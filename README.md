# API Connect - MVP

## 🎯 Objetivo da API
A API Connect é um MVP (Minimum Viable Product) desenvolvido para o gerenciamento de identidades e acessos de usuários. Ela fornece as operações essenciais de listagem, busca e criação de novos cadastros de forma centralizada e padronizada.

## 🛠️ Tecnologias Utilizadas
*   **Linguagem:** Python 3.x
*   **Framework:** Flask (Microframework web)
*   **Armazenamento:** Persistência temporária em memória (Mock Database)
*   **Arquitetura:** RESTful, utilizando formato JSON para o tráfego de dados.
